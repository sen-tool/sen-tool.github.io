# 특근매식비 내역서 만들기 · 사용법

## 무엇을 하는 도구인가

나이스에서 내려받은 초과근무 자료를 넣으면, 재정지원과 제출용 특근매식비 내역서를
엑셀로 만들어 줍니다. 손으로 옮겨 적는 과정을 없애 옮겨 적다 생기는 착오를 막습니다.

## 준비물

- 나이스 접속 권한 (본인 부서 초과근무 조회)
- 별도 설치나 프로그램은 필요 없습니다

## 사용 순서

**1) 나이스에서 자료 내려받기**

```
나이스 > 복무 > 초과근무관리 > 초과근무확인 > 기간설정 후 조회 > 엑셀다운
```

기간은 **반드시 한 달 단위**로 잡으세요. (예: 8월 1일 ~ 8월 31일)
두 달이 섞이면 도구가 막고 알려 줍니다.

**2) 확인대장도 함께 (선택)**

```
나이스 > 복무 > 초과근무관리 > 초과근무관리 > 기간설정 후 조회
      > 양식 출력 > 확인대장출력 > 엑셀다운
```

넣으면 결과 파일에 시트로 그대로 붙습니다. 넣지 않아도 됩니다.

**3) 도구 실행**

`특근매식비_내역서_만들기.html` 파일을 더블클릭하면 인터넷 창에서 열립니다.
(설치가 아니라 그냥 열리는 것입니다)

**4) 파일 넣기**

받은 엑셀을 화면에 끌어 놓거나, 눌러서 고릅니다. 순서는 상관없습니다.

**5) 화면에서 확인**

- 인원과 건수, 총액
- 내역서 미리보기 (엑셀에 들어갈 모양 그대로)
- 날짜별 내역 — 손계산과 대조해 보세요

**6) 내려받기**

「엑셀 파일로 내려받기」를 누르면 시트 4개짜리 파일이 저장됩니다.

| 시트 | 내용 |
|---|---|
| 특근매식비 내역 | 제출용 |
| 초과근무 현황(○○년 ○월) | 근거자료 |
| 초과근무 확인대장(○○년 ○월) | 넣었을 때만 |
| 검증표 | 대조용 — **제출 전 삭제하셔도 됩니다** |

## 계산 기준

한 사람의 하루 실제초과근무시간 합계가 **1시간 이상**이면 그 날 1건입니다.
하루에 여러 줄이 올라와 있어도 합쳐서 1건으로만 셉니다.

단가와 기준 시간은 화면에서 바꿀 수 있습니다.

## 이럴 때는 도구가 막습니다

| 화면 표시 | 뜻 | 할 일 |
|---|---|---|
| 성명 칸이 비어 있습니다 | 성명 없는 파일 | 성명이 있는 파일로 다시 받기 |
| 여러 달의 자료가 섞여 있습니다 | 두 달 이상 | 한 달씩 나눠서 다시 받기 |
| 읽지 못한 행 ○건 | 형식이 다른 줄 | 검증표에서 해당 행 확인 |

## 자주 묻는 것

**Q. 설치해야 하나요?**
아니요. 파일을 더블클릭하면 인터넷 창에서 바로 열립니다.

**Q. 자료가 외부로 나가지 않나요?**
나가지 않습니다. 모든 처리가 이 PC 안에서 이루어지고, 인터넷 연결도 필요 없습니다.

**Q. 업무망에서 되나요?**
됩니다. 인터넷 연결도 필요 없습니다.

**Q. 검증표는 제출해야 하나요?**
아닙니다. 대조용이라 지우고 제출하셔도 됩니다.

**Q. 결과를 믿어도 되나요?**
처음 한두 달은 기존 방식과 병행해 금액을 대조해 보신 뒤 쓰시기 바랍니다.

# 공사대장 만들기 · 사용법

## 무엇을 하는 도구인가

조달청 나라장터의 계약정보를 불러와 공사대장 엑셀을 만듭니다.
공사·물품·용역·외자를 한 번에 조회하고, 변경계약은 최종 차수만 남깁니다.

## 준비물

**1) 공공데이터포털 인증키** (무료)

도구 안 「발급 방법 보기」에 안내되어 있습니다. 요약하면,

1. 공공데이터포털에서 `조달청_나라장터 계약정보서비스` 활용신청
2. 대개 즉시 자동승인
3. 마이페이지 > 데이터활용 > Open API > 인증키
4. **일반 인증키(Decoding)** 를 복사

`Encoding` 키(% 기호가 섞인 것)를 넣으면 인증 오류가 납니다.

**2) 기관코드**

도구 안 「기관 이름으로 찾기」에서 검색해 고르면 자동으로 채워집니다.

## 사용 순서

1. `공사대장_만들기.html` 을 더블클릭
2. 인증키·기관코드 입력 (기관코드는 검색 가능)
3. 조회 기간 선택 — 「이번 달」 「올해」 등 버튼도 있습니다
4. 조회 대상 체크 (공사·물품·용역·외자)
5. 「조회 시작」
6. 결과 확인 후 「공사대장 엑셀로 내려받기」

인증키와 기관코드는 「이 브라우저에 저장하기」를 켜두면 다음에 자동으로 채워집니다.
**공용 PC에서는 켜지 마세요.**

## 조회가 안 될 때

조달청 서버(`apis.data.go.kr`)에 접속해야 하는 도구입니다.
기관 방화벽 정책에 따라 이 주소가 막혀 있을 수 있습니다.
그런 경우 접속이 되는 다른 PC에서 조회한 뒤, 내려받은 엑셀만 옮겨 쓰시면 됩니다.

## 결과 파일

계약 관련 21개 항목이 계약일 오래된 순으로 정리됩니다.

**주황색 칸은 비어서 나옵니다.** 나라장터에 없는 항목이라 직접 채우셔야 합니다.

- 발주일, 발주금액, 발주 담당자
- 검사검수일, 준공금액

나머지는 자동으로 채워지고, 금액은 숫자로 들어가 바로 합계를 낼 수 있습니다.

## 자주 묻는 것

**Q. 인증키가 꼭 필요한가요?**
네. 조달청 API를 쓰려면 개인별로 발급받아야 합니다. 무료이고 신청은 5분이면 됩니다.

**Q. 조회했는데 0건이 나옵니다.**
기관코드와 기간을 확인해 보세요. 기관 구분(수요기관/계약기관)을 바꿔 보셔도 됩니다.
오류 메시지가 있으면 화면 아래 진행 기록에 표시됩니다.

**Q. 「입력범위값 초과」가 나옵니다.**
조달청이 한 번에 처리할 수 있는 범위를 넘었다는 뜻입니다.
조회 기간을 짧게 잡아 보시거나 잠시 뒤 다시 시도해 보세요.

**Q. 인증키가 새어 나갈 위험은 없나요?**
인증키는 이 PC에만 저장되고, 조달청 서버 외에 어디로도 전송되지 않습니다.
다만 「이 브라우저에 저장하기」를 켜면 그 PC를 쓰는 사람이 볼 수 있으니
공용 PC에서는 켜지 마세요.
