# 홈페이지 전체 점검 — 2026-10-27

기준: PR #69까지 반영한 main(1e055c8). 수정 버전: v1.10.3.

## 수정한 문제

- OCR 키워드 누락·잘못된 연도·수동값과 제목의 충돌을 확인 대상으로 표시. 제목에서 자동값을 복원하는 버튼 추가. 두 자리 연도는 세기를 임의로 추측하지 않음.
- 다시 읽기 전에 수동 수정값이 사라짐을 확인. 실제 복사 실패를 성공으로 표시하지 않음.
- 내려받은 엑셀 A2:I를 대조표 B열에 붙이는 방법과 실물 1,000행/보유 3,000행 한도 안내.
- 대조표 양방향에서 학교명·키워드·유효 연도가 없는 행을 확정 일치에서 제외. 연도 숫자/텍스트·공백·년 표기와 학교 정식명/약칭을 정규화. 검색어의 와일드카드는 문자로 처리.
- 보유목록 G열은 같은 연도 후보 행 수로 변경. 다른 연도 후보나 권수와 혼동하지 않도록 안내. 학교명이 빈 실물 행도 위치별 확인필요·입력누락 경고에 집계.
- 전체 다운로드에 기록물 대조표 포함. 예시 실행 중 도구 변경 시 이전 주입 취소, 다운로드에도 20초 제한 적용.
- 셀 수정 시 표 전체를 다시 그리지 않아 다음 칸 포커스·버튼 클릭을 유지.

## 실제 확인

| 범위 | 결과 |
| --- | --- |
| HTML 9개(첫 화면+도구 8개) | 인라인 JS 문법, 로컬 링크·리소스 경로 통과 |
| 첫 화면·도구 8종·업데이트·의견 화면 | Chromium 로딩 오류 없음, 390px 가로 넘침 없음 |
| 특근매식비·초과근무 미입력·관내여비·고충민원·법정교육 | 제공 예시 실행 및 실제 XLSX 다운로드 성공 |
| 사진 OCR | 제공 사진 2장 → 11줄, XLSX 다운로드 성공 |
| 엑셀 취합기 | 기존 점검 중 안내 확인, 사용 중지 유지 |
| 공사대장 | 화면·코드 경로 점검. 실제 인증키 조회는 미실행 |
| 자동 회귀시험 | `npm test` 22개 통과(제목 분석/출력 6, 대조표 수식 13, 홈페이지 3) |
| 브라우저 회귀시험 | `npm run test:browser` 3개 통과(포커스/복원, 출력/복사 실패, 예시 주입 취소) |

수식 시험은 저장된 XLSX의 실제 수식을 읽어 HyperFormula에서 계산했다. 범위를 6행으로 줄인 독립 가상 입력으로 정상·다른 연도·빈 키워드·양쪽 빈 연도·연도 표기 혼합·OCR 오류·다른 학교·와일드카드·다른 연도 중복·빈 학교·두 자리 연도·정식 학교명·누락행 요약을 확인했다. 기존 파일로 같은 시험을 실행하면 누락값/후보수 등의 회귀시험이 실패함을 확인했다.

Excel 앱에서의 재계산·속도는 미확인이다. 별도 LibreOffice 실행 환경도 준비했으나 이 실행 환경에서는 변환 결과 파일이 생성되지 않아 검증 성공으로 기록하지 않았다. Artifact Tool은 CHAR(160) 평가에 호환성 한계가 있어 수식 검증의 근거로 삼지 않았다.

기존 드롭다운·조건부서식·주석·표시 서식·시트 순서는 원본 ZIP 파트를 보존하고, Artifact Tool로 작성한 수식/안내 셀만 반영했다. 계산용 보조열은 숨김 처리했다.

## 남아 있는 한계

- 학교명·키워드·연도가 같아도 설계도면과 준공도면 등 서로 다른 철일 수 있다. 「실물 있음」은 후보 일치이며 문서종류·관리번호·실물을 확인해야 한다. 자동 폐기 판정으로 쓰지 않는다.
- 같은 철을 중복 촬영하면 후보 행 수가 늘어난다. 범위 밖 행은 대조하지 않는다.
- 실제 조달청 API 응답·기관 방화벽·대용량 작업·실제 기기의 브라우저 차이는 이번 점검으로 보장하지 않는다.
- 여비·급량비·교육 인정기준의 법령 적합성 검토는 이번 소프트웨어 회귀 점검 범위에 포함하지 않았다.

## 다시 실행

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

설치된 브라우저를 쓰려면 `CHROMIUM_EXECUTABLE=/path/to/chromium`을 지정한다. 개발용 의존성은 시험에만 쓰며 배포되는 HTML에는 추가되지 않는다.

## 대조표 수식 재생성

Codex 기본 런타임의 Artifact Tool이 있는 환경에서, 임시 작업 디렉터리를 사용한다.

```sh
python scripts/package-record-template.py --slim samples/기록물_대조표_양식.xlsx /tmp/record-slim.xlsx
"$CODEX_PRIMARY_RUNTIME_NODE" scripts/build-record-template.mjs /tmp/record-slim.xlsx /tmp/record-draft
python scripts/package-record-template.py /tmp/record-draft/edited.xlsx samples/기록물_대조표_양식.xlsx
npm test
```

전체 파일의 수백만 셀 참조를 렌더러로 확장하지 않도록 작은 서식 복사본에서 행 2의 수식 원형을 작성한다. 원본 파일에 적용할 때 상대 행 참조만 확장하고 나머지 네이티브 파트는 보존한다.
